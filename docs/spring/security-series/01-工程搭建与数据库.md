# 第 01 章 工程搭建与数据库

> 本章目标：创建一个能启动的 `security-lab`，访问 `/api/ping` 返回 `{"status":"ok"}`，并且能连上 `security_lab` 数据库。

---

## 1.1 前置检查

确认第 00 章的环境和数据库已经就绪：

```bash
java -version
mvn -v
mysql --version
```

再确认数据库里有数据：

```sql
USE security_lab;
SELECT COUNT(*) FROM sys_user;        -- 期望 3
SELECT COUNT(*) FROM sys_role;        -- 期望 3
SELECT COUNT(*) FROM sys_permission;  -- 期望 12
```

如果表不存在或数量不对，回到第 00 章执行 `sql/01-schema.sql` 和 `sql/02-data.sql`。

## 1.2 创建工程

### 方式一：Spring Initializr 网页

打开 <https://start.spring.io>，按下表选择：

| 项 | 值 |
| --- | --- |
| Project | Maven |
| Language | Java |
| Spring Boot | 3.2.4 |
| Group | `com.keywin` |
| Artifact | `security-lab` |
| Name | `security-lab` |
| Package name | `com.keywin.security` |
| Packaging | Jar |
| Java | 17 |

右侧 Dependencies 添加：

- Spring Web
- Validation
- MySQL Driver
- Lombok

点击 Generate，解压到你自己的工作目录，例如 `F:\java\a-projects\security-lab`。

> 不要把工程建在 `docs/spring/security-series` 里面。文档目录只放教程。

### 方式二：IDEA 新建

IDEA → New Project → Spring Boot → 按上表填写 → 勾选同样四个依赖 → Create。

### 为什么还要手动加 MyBatis-Plus

Initializr 里没有 MyBatis-Plus。我们需要手动往 `pom.xml` 加依赖，并且**必须用 `mybatis-plus-spring-boot3-starter`**，不能用旧的 `mybatis-plus-boot-starter`。

## 1.3 完整 `pom.xml`

用下面的内容替换 `pom.xml`（如果你的 Initializr 版本略有差异，以这份为准）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.2.4</version>
        <relativePath/>
    </parent>

    <groupId>com.keywin</groupId>
    <artifactId>security-lab</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <name>security-lab</name>
    <description>Spring Security 6 + JWT 学习工程</description>

    <properties>
        <java.version>17</java.version>
        <mybatis-plus.version>3.5.5</mybatis-plus.version>
    </properties>

    <dependencies>
        <!-- Web：Controller、JSON、内嵌 Tomcat -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- 参数校验：@NotBlank、@Size、@Email -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

        <!-- MyBatis-Plus：Spring Boot 3 必须用 boot3-starter -->
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
            <version>${mybatis-plus.version}</version>
        </dependency>

        <!-- MySQL 驱动 -->
        <dependency>
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <scope>runtime</scope>
        </dependency>

        <!-- Lombok：减少 getter/setter -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <optional>true</optional>
        </dependency>

        <!-- 测试 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
                <configuration>
                    <excludes>
                        <exclude>
                            <groupId>org.projectlombok</groupId>
                            <artifactId>lombok</artifactId>
                        </exclude>
                    </excludes>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>
```

**本章故意不引入 `spring-boot-starter-security`。** 第 02 章才加，这样你能亲眼看到“加依赖前后”的变化。

## 1.4 完整 `application.yml`

把 `src/main/resources/application.yml` 改成：

```yaml
server:
  port: 8080

spring:
  application:
    name: security-lab
  datasource:
    url: jdbc:mysql://localhost:3306/security_lab?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    # 优先读环境变量 MYSQL_PASSWORD，没有就用 123456
    password: ${MYSQL_PASSWORD:123456}
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis-plus:
  configuration:
    # 数据库下划线字段 -> Java 驼峰属性
    map-underscore-to-camel-case: true
    # 控制台打印 SQL，学习阶段很有用
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
  global-config:
    banner: false
    db-config:
      # 主键策略：数据库自增
      id-type: auto
```

几点说明：

- `serverTimezone=Asia/Shanghai`：避免时间差 8 小时。
- `allowPublicKeyRetrieval=true`：MySQL 8 使用 `caching_sha2_password` 时常见要求。
- `log-impl` 会打印每条 SQL 和参数，后面排查“为什么查不到用户”非常有用。

如果你的 MySQL 密码不是 `123456`，可以：

```bash
# Git Bash / macOS / Linux
export MYSQL_PASSWORD=你的密码
```

或者直接改 `application.yml` 里的默认值。不要把真实密码提交到 git。

## 1.5 主类

`src/main/java/com/keywin/security/SecurityLabApplication.java`：

```java
package com.keywin.security;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SecurityLabApplication {

    public static void main(String[] args) {
        SpringApplication.run(SecurityLabApplication.class, args);
    }
}
```

`@SpringBootApplication` 是三个注解的组合：

- `@SpringBootConfiguration`：声明这是配置类
- `@EnableAutoConfiguration`：根据依赖自动装配（Web、数据源、MyBatis-Plus 等）
- `@ComponentScan`：扫描当前包及子包

所以主类必须放在 `com.keywin.security` 根包，后面的 `config`、`security`、`modules` 都在它下面。

## 1.6 一个用来验证的 PingController

`src/main/java/com/keywin/security/PingController.java`：

```java
package com.keywin.security;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.Map;

@RestController
public class PingController {

    @GetMapping("/api/ping")
    public Map<String, String> ping() {
        return Map.of("status", "ok");
    }
}
```

它只有一个作用：证明应用启动、Web 层正常、JSON 序列化正常。后面即使权限接口出问题，这个接口也能帮你判断“是不是整个应用挂了”。

## 1.8 启动与验证

### 启动

在工程根目录（有 `pom.xml` 的那一层）执行：

```bash
mvn spring-boot:run
```

或者直接在 IDEA 里运行 `SecurityLabApplication`。

### 看启动日志

启动成功的标志：

```text
Tomcat started on port 8080 (http)
Started SecurityLabApplication in 3.2 seconds (process running for 3.5)
HikariPool-1 - Start completed.
```

如果看到 `HikariPool-1 - Start completed.`，说明数据库连接也成功了。

### 验证接口

另开一个终端：

```bash
curl -i http://localhost:8080/api/ping
```

预期：

```text
HTTP/1.1 200
Content-Type: application/json

{"status":"ok"}
```

到这里，第 01 章完成。

### 验证数据库连接

方式一：看启动日志有没有 `HikariPool-1 - Start completed.`

方式二：写一个临时查询（可选）。本章还没有 Mapper，最直接的是用 MySQL 客户端：

```sql
USE security_lab;
SELECT id, username, nickname, status, token_version FROM sys_user;
```

预期三行：

```text
1  admin       超级管理员   1  0
2  user_admin  用户管理员   1  0
3  viewer      只读用户     1  0
```

## 1.9 常见报错

### 1. 端口被占用

现象：

```text
Web server failed to start. Port 8080 was already in use.
```

排查：

```bash
# Windows
netstat -ano | findstr :8080

# Git Bash / macOS / Linux
lsof -i :8080
```

解决：结束占用端口的进程，或者把 `application.yml` 的 `server.port` 改成 `8081`（后面所有 curl 地址也要跟着改）。

### 2. `Access denied for user 'root'@'localhost'`

原因：`application.yml` 里的密码不对。

解决：设置环境变量 `MYSQL_PASSWORD`，或直接修改默认值。

### 3. `Unknown database 'security_lab'`

原因：没有执行 `sql/01-schema.sql`。

解决：回到第 00 章执行建库脚本。

### 4. MyBatis-Plus 启动报 `Invalid value type for attribute 'factoryBeanObjectType'`

原因：用了旧的 `mybatis-plus-boot-starter`，它不兼容 Spring Boot 3。

解决：确认依赖是：

```xml
<artifactId>mybatis-plus-spring-boot3-starter</artifactId>
```

### 5. Lombok 的 getter/setter 报红

原因：IDEA 没开注解处理。

解决：

- IDEA → Settings → Build, Execution, Deployment → Compiler → Annotation Processors → 勾选 Enable annotation processing
- 或者安装 Lombok 插件

### 6. `mvn` 找不到命令

原因：Maven 没配 PATH。

解决：用 IDEA 自带的 Maven，或者把 Maven 的 `bin` 目录加入 PATH。

## 1.10 本章小结

- 工程坐标：`com.keywin.security`、`security-lab`、8080。
- 依赖：Web、Validation、MyBatis-Plus（boot3 starter）、MySQL、Lombok。
- 本章**没有**引入 Spring Security。
- `/api/ping` 返回 `{"status":"ok"}`，说明 Web 层正常。
- 启动日志出现 `HikariPool-1 - Start completed.`，说明数据库连接正常。

### 自测题

1. 为什么 MyBatis-Plus 必须用 `mybatis-plus-spring-boot3-starter`？
2. `@SpringBootApplication` 包含哪三个注解？各自做什么？
3. 如果 `/api/ping` 返回 404，而不是 500，问题更可能出在哪一层？

<details>
<summary>参考答案</summary>

1. 旧 starter 基于 Spring Boot 2 的自动装配机制，Boot 3 下会报 `factoryBeanObjectType` 之类的错误。
2. `@SpringBootConfiguration`（配置类）、`@EnableAutoConfiguration`（自动装配）、`@ComponentScan`（扫描当前包及子包）。
3. 404 说明应用和 Web 层正常，但路径没有映射到 Controller。检查 `@GetMapping("/api/ping")` 和包扫描路径。

</details>
