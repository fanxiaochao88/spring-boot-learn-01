## 12.3 测试一：JwtService 单元测试

这个测试不启动 Spring 上下文，也不连数据库，只验证 JWT 的生成和解析。

`src/test/java/com/keywin/security/security/JwtServiceTest.java`：

```java
package com.keywin.security.security;

import com.keywin.security.modules.user.entity.SysUser;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import java.util.Set;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class JwtServiceTest {

    private JwtService jwtService;

    @BeforeEach
    void setUp() {
        JwtProperties properties = new JwtProperties();
        properties.setSecret("security-lab-test-secret-key-at-least-32-bytes");
        properties.setIssuer("security-lab-test");
        properties.setExpirationMinutes(30);

        jwtService = new JwtService(properties);
        jwtService.init();
    }

    @Test
    void generateAndParse() {
        SysUser user = new SysUser();
        user.setId(1L);
        user.setUsername("admin");
        user.setPasswordHash("x");
        user.setStatus(1);
        user.setTokenVersion(3);

        LoginUser loginUser = new LoginUser(
                user, Set.of("SUPER_ADMIN"), Set.of("user:list"));

        String token = jwtService.generateToken(loginUser);

        assertThat(token).isNotBlank();
        assertThat(jwtService.extractUserId(token)).isEqualTo(1L);
        assertThat(jwtService.extractUsername(token)).isEqualTo("admin");
        assertThat(jwtService.extractTokenVersion(token)).isEqualTo(3);
        assertThat(jwtService.getExpirationSeconds()).isEqualTo(1800);
    }

    @Test
    void tamperedTokenFails() {
        SysUser user = new SysUser();
        user.setId(1L);
        user.setUsername("admin");
        user.setPasswordHash("x");
        user.setStatus(1);
        user.setTokenVersion(0);

        String token = jwtService.generateToken(
                new LoginUser(user, Set.of(), Set.of()));

        // 改签名段的第一个字符，确保一定与原 Token 不同。
        // 不要改最后一个字符：它可能本来就是 x，导致 token 没变。
        int lastDot = token.lastIndexOf('.');
        char original = token.charAt(lastDot + 1);
        char replacement = original == 'a' ? 'b' : 'a';
        String tampered = token.substring(0, lastDot + 1)
                + replacement
                + token.substring(lastDot + 2);

        assertThatThrownBy(() -> jwtService.parse(tampered))
                .isInstanceOf(io.jsonwebtoken.JwtException.class);
    }
}
```

关键点：

- `JwtProperties` 直接 `new`，不走 Spring 注入。
- 手动调用 `jwtService.init()`，因为 `@PostConstruct` 在单元测试里不会自动执行。
- 密钥长度必须 >= 32 字节，否则 `WeakKeyException`。
- 篡改最后一个字符，`parse` 应该抛 `JwtException`。

## 12.4 测试二：安全集成测试

这个测试启动完整的 Spring 上下文，连真实 MySQL，用真实登录拿 Token。

`src/test/java/com/keywin/security/SecurityIntegrationTest.java`：

```java
package com.keywin.security;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.AutoConfigureMockMvc;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.test.web.servlet.MvcResult;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@SpringBootTest
@AutoConfigureMockMvc
class SecurityIntegrationTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @Test
    void pingIsPublic() throws Exception {
        mockMvc.perform(get("/api/ping"))
                .andExpect(status().isOk());
    }

    @Test
    void requestWithoutTokenReturns401() throws Exception {
        mockMvc.perform(get("/api/users"))
                .andExpect(status().isUnauthorized())
                .andExpect(jsonPath("$.code").value(401));
    }

    @Test
    void viewerCanListUsers() throws Exception {
        String token = login("viewer", "viewer123");

        mockMvc.perform(get("/api/users")
                        .header("Authorization", "Bearer " + token))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(200));
    }

    @Test
    void viewerCannotCreateUser() throws Exception {
        String token = login("viewer", "viewer123");

        mockMvc.perform(post("/api/users")
                        .header("Authorization", "Bearer " + token)
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"username":"it_viewer_create","password":"123456","status":1}
                                """))
                .andExpect(status().isForbidden())
                .andExpect(jsonPath("$.code").value(403));
    }

    @Test
    void adminCanAccessAdminDemo() throws Exception {
        String token = login("admin", "admin123");

        mockMvc.perform(get("/api/admin/demo")
                        .header("Authorization", "Bearer " + token))
                .andExpect(status().isOk());
    }

    @Test
    void viewerCannotAccessAdminDemo() throws Exception {
        String token = login("viewer", "viewer123");

        mockMvc.perform(get("/api/admin/demo")
                        .header("Authorization", "Bearer " + token))
                .andExpect(status().isForbidden());
    }

    @Test
    void logoutInvalidatesOldToken() throws Exception {
        String token = login("viewer", "viewer123");

        mockMvc.perform(post("/api/auth/logout")
                        .header("Authorization", "Bearer " + token))
                .andExpect(status().isOk());

        mockMvc.perform(get("/api/auth/me")
                        .header("Authorization", "Bearer " + token))
                .andExpect(status().isUnauthorized());
    }

    /**
     * 登录并返回 Token。
     */
    private String login(String username, String password) throws Exception {
        MvcResult result = mockMvc.perform(post("/api/auth/login")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"username":"%s","password":"%s"}
                                """.formatted(username, password)))
                .andExpect(status().isOk())
                .andReturn();

        JsonNode body = objectMapper.readTree(
                result.getResponse().getContentAsString());
        return body.path("data").path("token").asText();
    }
}
```

这些测试覆盖：

| 测试 | 验证什么 |
| --- | --- |
| `pingIsPublic` | 公开接口不需要 Token |
| `requestWithoutTokenReturns401` | 未登录返回 401 |
| `viewerCanListUsers` | viewer 有 `user:list` |
| `viewerCannotCreateUser` | viewer 没有 `user:add`，返回 403 |
| `adminCanAccessAdminDemo` | admin 有 `ROLE_SUPER_ADMIN` |
| `viewerCannotAccessAdminDemo` | viewer 没有管理员角色，返回 403 |
| `logoutInvalidatesOldToken` | 退出后旧 Token 立即 401 |

## 12.5 测试三：`@WithMockUser` 方法级测试

### 12.5.1 为什么需要专门的端点

`@WithMockUser` 会伪造一个 Spring 内置的 `User`，principal 不是我们的 `LoginUser`。

如果测试的接口用了 `@AuthenticationPrincipal LoginUser`，会拿到 null，导致 NPE。所以方法级测试要用一个**不需要 principal** 的端点。

在 `DemoController` 里加一个：

`src/main/java/com/keywin/security/modules/demo/DemoController.java` **完整替换为**：

```java
package com.keywin.security.modules.demo;

import com.keywin.security.common.api.Result;
import com.keywin.security.security.LoginUser;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.Map;

@RestController
@RequestMapping("/api/demo")
public class DemoController {

    @GetMapping("/public")
    public Result<String> publicApi() {
        return Result.success("public ok");
    }

    @GetMapping("/me")
    public Result<Map<String, Object>> me(@AuthenticationPrincipal LoginUser loginUser) {
        return Result.success(Map.of(
                "userId", loginUser.getUserId(),
                "username", loginUser.getUsername(),
                "roles", loginUser.getRoles(),
                "permissions", loginUser.getPermissions()
        ));
    }

    /**
     * 专用于测试方法级授权：URL 规则只要求登录，
     * 方法级要求 user:list。
     */
    @GetMapping("/method-check")
    @PreAuthorize("hasAuthority('user:list')")
    public Result<String> methodCheck() {
        return Result.success("method ok");
    }
}
```

`/api/demo/method-check` 在 `SecurityConfig` 里没有专门的 URL 规则，会落到 `anyRequest().authenticated()`。所以：

- 没登录 → 401
- 登录但没 `user:list` → 方法级 403
- 有 `user:list` → 200

### 12.5.2 测试类

`src/test/java/com/keywin/security/MethodSecurityTest.java`：

```java
package com.keywin.security;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.AutoConfigureMockMvc;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.security.test.context.support.WithMockUser;
import org.springframework.test.web.servlet.MockMvc;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@SpringBootTest
@AutoConfigureMockMvc
class MethodSecurityTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    @WithMockUser(authorities = "user:list")
    void userWithListAuthorityPasses() throws Exception {
        mockMvc.perform(get("/api/demo/method-check"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.data").value("method ok"));
    }

    @Test
    @WithMockUser(authorities = "user:add")
    void userWithoutListAuthorityGets403() throws Exception {
        mockMvc.perform(get("/api/demo/method-check"))
                .andExpect(status().isForbidden())
                .andExpect(jsonPath("$.code").value(403));
    }

    @Test
    void anonymousGets401() throws Exception {
        mockMvc.perform(get("/api/demo/method-check"))
                .andExpect(status().isUnauthorized());
    }
}
```

`@WithMockUser` 的作用：

- 直接把一个伪造的 `Authentication` 放进 `SecurityContext`。
- 不会经过你的 `JwtAuthenticationFilter`（因为请求没有 `Authorization` 头，过滤器直接放行）。
- 非常适合单独测试授权规则，不用造 Token。

## 12.7 测试注意事项

### 1. 测试会改数据库

`logoutInvalidatesOldToken` 会把 viewer 的 `token_version` +1。

- 其他测试每次重新登录，拿到的是最新版本，不受影响。
- 如果你手动 curl 用的是旧 Token，会 401，重新登录即可。
- 测试前可以执行 `sql/02-data.sql` 重置。

### 2. 不要开启测试并行

默认 JUnit 5 是顺序执行的。如果你在 `junit-platform.properties` 里开了并行，多个测试同时改 `token_version` 会互相影响。

### 3. 为什么不用 H2

H2 和 MySQL 在外键、大小写、`ON DELETE CASCADE`、`DATETIME` 默认值上都有差异。学习阶段直接用 MySQL，测试环境更接近真实。

### 4. `@WithMockUser` 的 principal 不是 `LoginUser`

所以：

- 测 `@PreAuthorize` 用 `@WithMockUser`。
- 测 `@AuthenticationPrincipal LoginUser` 用真实 Token + `MockMvc`，或者 `@WithUserDetails`。

### 5. 测试上下文启动慢

`@SpringBootTest` 会启动完整 Spring 上下文，第一次可能 5~10 秒。正常。

## 12.8 用 `http/api.http` 做人工验收

IDEA 打开 `http/api.http`，按顺序执行：

```text
1. ping
2. 登录 admin / user_admin / viewer
3. 当前用户
4. 用户 CRUD
5. 分配角色
6. 角色 CRUD
7. 分配权限
8. 权限 CRUD
9. demo public / me / admin
10. 退出登录
11. 旧 Token 访问 -> 401
12. 重新登录 -> 200
13. 清理测试数据
```

重点看：

- 不带 Token 的受保护接口 → 401
- viewer 新增用户 → 403
- viewer 访问 `/api/admin/demo` → 403
- admin 全部通过
- 退出后旧 Token → 401

## 12.9 常见报错

### 1. `Table 'security_lab.sys_user' doesn't exist`

原因：测试库没建表。

解决：执行 `sql/01-schema.sql` 和 `sql/02-data.sql`。

### 2. `viewerCannotCreateUser` 失败，返回 200

原因：viewer 被第 10 章的实验改成了 `USER_ADMIN`，或者权限没恢复。

解决：

```sql
-- 查看 viewer 的角色
SELECT r.code
FROM sys_role r
JOIN sys_user_role ur ON ur.role_id = r.id
WHERE ur.user_id = 3;
```

应该是 `VIEWER`。不是就重新执行 `sql/02-data.sql`。

### 3. `logoutInvalidatesOldToken` 失败，旧 Token 还是 200

原因：

- 过滤器没校验 `tokenVersion`
- `incrementTokenVersion` 没执行
- 数据库里 `token_version` 是 null

解决：检查第 11 章的三处代码和数据库默认值。

### 4. `JwtServiceTest` 报 `WeakKeyException`

原因：测试密钥少于 32 字节。

解决：用 `security-lab-test-secret-key-at-least-32-bytes`（长度足够）。

### 5. `@WithMockUser` 测试返回 500

原因：接口用了 `@AuthenticationPrincipal LoginUser`，但 principal 是 Spring 内置 `User`，转换后为 null，方法里 NPE。

解决：用 `/api/demo/method-check` 这种不需要 principal 的端点，或者用真实 Token。

### 6. 测试启动报端口被占用

原因：`@SpringBootTest` 默认 `webEnvironment = MOCK`，不占端口；如果你改成了 `RANDOM_PORT` 或 `DEFINED_PORT`，可能冲突。

解决：保持默认，或者用 `RANDOM_PORT`。

### 7. 所有测试 401

原因：测试没带 Token，或者 Token 过期。

解决：确认 `login()` 返回的 token 非空；打印出来看看。

## 12.10 本章小结

- `JwtServiceTest`：纯单元测试，不启动 Spring。
- `SecurityIntegrationTest`：启动完整上下文，真实登录 + 真实权限。
- `MethodSecurityTest`：`@WithMockUser` 专注测方法级授权。
- 测试前恢复种子数据，避免手工实验污染。
- `http/api.http` 用于人工验收完整流程。
